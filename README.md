# unfold

Custom cardboard boxes, made simple — design online, quote in 24 hours.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Customise

- **Brand name**: search/replace `unfold` in `index.html`
- **Contact details**: update email/phone in the quote section and `scripts/main.js`
- **Colours**: edit CSS variables in `styles/main.css` (`--accent`, etc.)
